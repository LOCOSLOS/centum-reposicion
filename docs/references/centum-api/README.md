# Manuales de la API pública de Centum

Estos archivos provienen del repositorio `LOCOSLOS/Dash-Estados-De-Resultados` y fueron incorporados localmente al proyecto el 24 de julio de 2026.

- `API_Publica.pdf`: referencia general de la API pública.
- `API_Publica_Anexo_Ejemplos.pdf`: ejemplos complementarios.

Son documentación de referencia. No contienen la configuración productiva de los workflows de n8n ni reemplazan las validaciones realizadas con respuestas reales.

Los PDF no se publican en el repositorio porque son documentación de un tercero. El `.gitignore` conserva esta carpeta como ubicación local estable y permite versionar únicamente este inventario.

Al investigar un endpoint, buscar primero por el nombre concreto del recurso o campo. Evitar copiar respuestas completas de producción a documentación, issues o commits.
